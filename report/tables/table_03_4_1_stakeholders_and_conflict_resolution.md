# Table 3: Stakeholders and conflict resolution

From the final report, section "4.1 Stakeholders and conflict resolution".

| Conflict | Resolution |
| --- | --- |
| 1. When students see marks (Principal against lecturer) | Lecturer marks and writes feedback; the HoD approves; students see marks only after release |
| 2. Extensions (rules missing) | Lecturer records an individual extension; the new deadline is used to decide lateness; school to confirm whether proof is needed |
| 3. Late work (HoD penalty against student wish for no rejection) | Late work is accepted for up to three days with a 10% per day penalty; after that it is accepted but receives zero; a part-day counts as a full day |
| 4. Resubmission (limit and version unclear) | Students may resubmit before the deadline; the latest valid version is marked |
| 5. Written feedback (not always required) | Feedback is saved with the mark and shown only after release; implementation requires feedback for every mark |
| 6. Offline and fast | Local SQLite database, no internet needed, passwords as salted hashes, tested with 800 students |
| 7. Easy to use | Simple role-specific menus and clear messages |

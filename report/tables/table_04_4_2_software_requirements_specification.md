# Table 4: Software requirements specification

From the final report, section "4.2 Software requirements specification".

| ID | Functional requirement | Priority |
| --- | --- | --- |
| FR-01 | Users log in with their account details | Must |
| FR-02 | Each user is limited to what their role allows | Must |
| FR-03 | The administrator creates and manages user accounts | Must |
| FR-04 | The administrator manages courses, departments and enrolments | Must |
| FR-05 | Lecturers create assignments with title, instructions, deadline and total mark | Must |
| FR-06 | Students see the assignments of their courses (v1.1: with any extension shown) | Must |
| FR-07 | Students submit work | Must |
| FR-08 | Students fix and resubmit work before the deadline | Must |
| FR-09 | Lecturers record an extension for a student | Must |
| FR-10 | The system works out late penalties from the correct deadline | Must |
| FR-11 | Lecturers record marks and written feedback | Must |
| FR-12 | The HoD reviews marks and approves release before students see them | Must |
| FR-13 | Every mark change is recorded: who, when, old mark, new mark, reason | Must |
| FR-14 | Users see the information they need for their work | Should |
| FR-15 | Lecturers extend a deadline for a whole class at once (CR1, v1.1) | Should |

# Table 5: Software requirements specification

From the final report, section "4.2 Software requirements specification".

| ID | Non-functional requirement (measurable) | Priority |
| --- | --- | --- |
| NFR-01 | Login takes 2 seconds or less with 800 students stored | Should |
| NFR-02 | A normal database action takes 2 seconds or less with 800 students | Should |
| NFR-03 | Main functions work with no internet | Must |
| NFR-04 | Passwords are stored only as salted hashes from a trusted library | Must |
| NFR-05 | A user cannot see or change what their role does not allow | Must |
| NFR-06 | Bad input or database problems give a clear message and no crash | Must |
| NFR-07 | Clear menus for each role's main tasks, checked with one test user per role | Should |
| NFR-08 | Every mark change has a full audit record | Must |
